# 수학 디딤돌

`dist/index.html`에서 실행하는 정적 학습 사이트입니다. 서버와 학생 계정 없이 동작합니다.

17개 주제에 확인 2문항, 보충 2문항, 재도전 2문항으로 기본 102문항을 제공합니다. 문제는 사이트 자체 제작이며 교육과정 근거는 한국 초등 학습지도 MCP의 3~4학년군 수학 47개 성취기준입니다. 학년 배치와 주제 간 보충 연결은 공식 학년 구분이 아닌 사이트의 수업 설계입니다.

학습 데이터는 `dist/app.js`의 topics에 있습니다. 각 항목은 제목, 영역 번호, 성취기준 코드, 보충 개념명, 개념 설명, 예제, 6문항 순서입니다. 문항은 질문, 정답, 선택지(선택형만)로 구성합니다.

현재 기록은 `didim-v1` localStorage에 저장합니다. 이름은 수집하지 않습니다. 인쇄는 학습 기록과 전체 확인 문제지·정답지를 지원합니다.

검증: JavaScript 문법, 17개 주제/102문항, 보기와 정답 일치, 분수·소수 동치 답 처리를 확인했습니다.

콘텐츠 한계: 자동 채점은 선택형과 짧은 답 문항의 결과이며 작도·설명의 성취를 직접 평가하지 않습니다. 반복 보충은 고정된 문항을 재사용합니다. 그래프 영역은 수치와 문장으로 제시합니다.
